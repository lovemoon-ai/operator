# 多壳体装配 STL 被当作单件打印导致零件熔合

- Date: 2026-09-09
- Status: Active
- Incident artifact: `cable_protecter_huacao.STL`

## Trigger Conditions

以下任一条件出现时，本 lesson 适用：

- 单个 STL 含两个或更多互不连通的 closed shell / connected component。
- 模型看起来像壳体、盖板、背板、卡扣、铰链或其他装配体。
- 多个 shell 的包围盒重叠，或以装配位置嵌套、贴合。
- 最终 3MF 的对象/part 数少于 STL 的独立 shell 数。
- 用户要求零件打印后可以分开、活动或装配，但输入未明确拆件。

## Symptom

打印任务正常完成、外观也可能基本正常，但本应分开的壳体和背板在接触边缘或配合面熔合，
无法无损拆开。

## Direct Cause

原始 STL 中有两个独立闭合实体，却以装配位置保存在同一个 STL 内；两实体最小表面间隙只有
约 `0.10 mm`。切片时它们被保留为一个对象和一个 part，在 `0.4 mm` 喷嘴、约
`0.42–0.50 mm` 线宽下同时打印。该间隙远小于可靠的打印分离尺度，实际挤出、首层压扁和
尺寸误差使两部分熔合。

## Root Cause

- 几何检查发现两个 connected component，但未经用户或 CAD 证据确认，就把它们解释为
  “同一零件的两个 shell”。
- 需求关卡没有明确“期望物理零件数”和“打印后是否必须分离”。
- 没有把多 shell 单 STL 作为强制停机条件，也没有计算 shell 间最小间隙并与实际线宽比较。
- 预览使用同一颜色展示整个 STL，没有生成分组件着色图，掩盖了壳体和背板是两个零件。
- 最终 3MF 只有一个对象、一个 part、一个 G-code `OBJECT_ID`，但对象数量审核仍被错误判为
  通过。

## Contributing Factors

- 两个 shell 都是闭合、流形网格，因此常规网格健康检查不会报错。
- STL 文件名和用户最初指令没有显式说明包含两个可拆件。
- 两个零件处于合理的最终装配位置，单色预览容易被误认为一体结构。
- 审核注意力集中在壁厚、桥接和打印强度，没有优先解决零件身份与数量。

## Evidence

- Bambu Studio `--info`：`number_of_parts = 2`。
- 几何连通域：2 个 closed shell，分别为 14,328 和 2,570 个三角面。
- 外壳尺寸：`140 × 72 × 47 mm`；背板尺寸：`135.8 × 45 × 5.9 mm`。
- 两个包围盒在 XYZ 三轴均重叠，重叠尺寸为 `135.8 × 45 × 5.9 mm`。
- 计算得到最小表面间隙约 `0.09999 mm`，并在 X、Y、Z 多个配合面重复出现。
- 切片配置：喷嘴 `0.4 mm`，普通线宽 `0.42 mm`，内墙 `0.45 mm`，首层 `0.50 mm`。
- 最终 3MF：1 个 object、1 个 part；G-code 的 235 层均只有 `OBJECT_ID: 15`。
- 用户实物反馈：打印完成后壳体与背板连在一起，无法分开。

## Required Controls

1. 对每个 STL 在切片前统计 connected component / closed shell 数。
2. 只要 shell 数大于 1，就把每个 shell 暂按独立零件处理；不得根据文件名或装配外观自行合并语义。
3. 输出分组件着色预览，并为每个 shell 报告尺寸、位置、体积和床面接触。
4. 计算 shell 间最小表面间隙和包围盒关系；若包围盒重叠，必须检查相交、贴合或打印中粘连风险。
5. 需求关卡必须明确记录期望物理零件数，以及打印后是否需要分离、活动或装配。
6. 需要分开的零件必须成为独立对象，并在打印盘上分开排布；不得保留装配坐标直接打印。
7. 若用户明确要求 print-in-place，间隙必须经过材料、喷嘴、层高和方向对应的验证；未经验证时，
   小于一条标称外墙线宽的间隙按 `FAIL` 处理。
8. 最终 3MF 的对象/part 数必须与已确认的物理零件数一致；G-code 中也应能逐对象审核。

## Blocking Conditions

以下任一条件存在时禁止打印：

- 单个输入含多个 shell，但期望零件数尚未由用户或设计资料确认。
- 可拆零件仍以装配位置存在于同一对象中。
- 多 shell 之间最小间隙小于标称外墙线宽，且没有经过验证的 print-in-place 设计依据。
- 分组件预览缺失，或无法判断各 shell 的身份、接触和间隙。
- 最终 3MF 对象/part 数少于已确认的物理零件数。

## Verification Evidence

发布报告必须包含：

- 输入 shell 数和期望物理零件数。
- 分组件着色预览。
- 每个组件的尺寸、朝向和盘上位置。
- 组件间最小间隙及其与喷嘴/线宽的比较。
- 最终 3MF object、part 和 G-code object ID 数量。
- 若为可拆件，证明它们在盘上有独立、非重叠的首层区域。

## Recovery / Remediation

- 从原 STL 中提取外壳和背板为两个独立 STL。
- 分别确定稳定朝向、支撑和强度参数，再在打印盘上留出明确间距排布。
- 不通过减小流量或“打印后硬掰”补救 `0.10 mm` 装配间隙。
- 重新切片后执行完整 Lesson Gate，并只重打需要的独立零件。
